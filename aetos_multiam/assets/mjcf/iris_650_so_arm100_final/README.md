# Iris 650 mm + 原尺寸 SO-ARM100（最终独立运行包）

双击 `打开650mm机载机械臂.command`，在 MuJoCo 中运行机载机械臂悬停演示。
入口为 scene.xml，主体为 robot.xml。XML、网格、控制代码与参数均在本目录内，运行无需原工程。
当前已验证环境：macOS、Python 3.10、MuJoCo 3.13.0、NumPy 1.23.3。

## 装配与交互

- Iris 的机架与桨叶统一放大至两条对角轴距均为650 mm；不包含桨叶尖端的总外廓尺寸。
- 无人机保留6自由度，SO-ARM100通过60 g的概念转接板刚性安装在中央机身下方。
- SO-ARM100保持原尺寸、全部6个关节（5个机械臂关节+1个夹爪关节）、源模型质量和惯量。
- Base 绕X旋转180°，整个挂载组件另绕机体Z轴旋转-90°，使初始夹爪位于机头+X方向；安装面位于机体系 z=-0.072839416 m；转接板顶部与中央机身底部贴合。
- 初始机械臂姿态取源 home 的前5个角度，夹爪改为0.8 rad张开。
- Space暂停/继续；R重置；G切换夹爪：0.8 rad张开、-0.174 rad闭合。
- Control 面板前5个滑块为机械臂目标角度（rad），四个旋翼推力由悬停控制器更新。
- 旋翼没有桨轴旋转自由度，视觉桨叶不旋转；其质量/惯量并入机体并由site施加推力与反扭矩。

源SO-ARM100伺服配置保留：kp=50、dampratio=1、armature=0.1、frictionloss=0.1、力矩限制±3.5 N·m。
不要把这些统一的源模型伺服参数当作每个实物舵机的实测数据。

## 尺寸与质量调整

几何来自本地 amov_omni 的 iris.usd，原两条对角电机中心距约0.493963558 m。
按实际USD旋翼位置计算，均匀缩放系数 s=1.315886546，缩放后对角中心距均为0.65 m。
机体、旋翼几何、旋翼中心位置和碰撞近似保持相同比例，使用源USD全部局部变换。
MDL材质未移植，采用近似深色外观。

采用等密度几何相似假设：质量乘s³=2.278533088，惯量乘s⁵=3.945410834。

| 组成 | 模型质量 |
|---|---:|
| 放大后的无人机（机身+旋翼） | 3.46337 kg |
| 原尺寸SO-ARM100 | 1.17143 kg |
| 概念转接板 | 0.06000 kg |
| 总计 | 4.69480 kg |

机械臂质量由原MJCF编译得到，包含Base碰撞网格按默认密度推断的质量；不是实物称量。
转接板为124×104×20 mm的轻量化结构占位件，未完成孔位/螺纹/强度设计。

## 源惯量修正

Iris源USD的机身对角惯量为(0.034756299,0.045892902,0.097700000) kg·m²，
不满足 Ixx+Iyy>=Izz，因此MuJoCo拒绝加载。
本模型保留Ixx、Iyy，将Izz限制为0.999×(Ixx+Iyy)=0.080568552，然后再乘s⁵。
这是使源参数物理可行的建模修正，不是重新辨识。原始、修正和缩放后的值均记录在flight_parameters.json。
源USD旋翼未定义质心、主轴四元数为全零；质心取旋翼原点，惯量轴按单位旋转解释。

## 推进系统重新配置

几何相似且保持相同最大桨尖速度时，原推进系统对应的最大推重比约0.903，无法悬停。
因此本模型定义升级后的概念推进系统，以整机最大推重比2.0为设计目标：

- 静态力系数 kf 随桨尺寸乘s⁴，力矩系数 km 乘s⁵。
- 每个旋翼推力上限23.0280 N，总推力上限92.1120 N。
- 对应设计最大转速947.860 rad/s（约9051 RPM）。
- 静态悬停配平每桨约10.07–12.96 N，考虑倒挂机械臂带来的偏心重力矩。
- site执行器同时施加竖向推力与对应旋向的反扭矩；data.ctrl的旋翼输入单位为N。

这些是所需推进能力的仿真设计参数，尚未与具体电机、桨叶、ESC、电池或推力台测量匹配。
悬停演示使用基础位置/姿态反馈及组合系统重力矩补偿；未包含电机响应、下洗、风场、电池与原OmniDrones策略。

## 验证与文件

validate.py完成10秒静止悬停、多个机械臂关节缓慢运动和夹爪闭合测试。
当前结果：最大位置误差约2.90 mm、最大倾角约0.111°，无推力饱和、无数值警告；所测姿态无碰撞接触。
这不代表已验证全关节范围、快速运动、外部抓取负载或真实飞行。

- assets/drone/：转换后的Iris机体与四个旋翼OBJ网格。
- assets/so_arm100/：原SO-ARM100 STL网格。
- flight_parameters.json：尺寸、质量、惯量修正、旋翼分配与推进设计参数。
- flight_control.py、launch.py：基础悬停控制和交互演示。
- validation.json：测试结果。
- assembly_preview.png、mount_preview.png：整体与安装细节。
- requirements.txt：运行依赖；预览渲染另需Pillow。
- LICENSE_OmniDrones、LICENSE_SO_ARM100：源资产许可。

其他macOS环境可创建Python 3.10虚拟环境，安装requirements.txt后执行 `mjpython launch.py`。
Linux/Windows使用 `python launch.py`，未在本机之外实测。
源项目及原机械臂目录均未修改。

方向验证：OmniDrones以机体+X为heading。当前home姿态的grasp_tcp相对安装面为(0.2389078,0,-0.0866471) m，位于机头方向；后续关节动作仍可改变夹爪位置。本包仅保留已确认的机头朝向版本。

## 独立保存说明

本包包含当前已确认朝向的完整模型资产和运行脚本，不依赖原amov_omni、trs_so_arm100或制作目录。所有XML资源引用均为相对路径，可整体复制或移动。仍需Python/MuJoCo运行环境；当前电脑可双击启动，其他电脑可参考requirements.txt配置Python 3.10环境。构建脚本、旧方向备份、缓存及历史运行日志未打包。manifest.json为文件SHA-256清单，package_check.json为独立加载验证结果。
